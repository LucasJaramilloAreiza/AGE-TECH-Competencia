# Staging

Este directorio se usa para almacenar los microdatos autorizados de SABE y MHAS.

No se publica aquí ni se sube al repositorio público.

Estructura sugerida:

`	ext
staging/
├── sabe/
│   └── <microdatos autorizados de SABE Colombia 2015>
└── mhas/
    └── <microdatos autorizados de MHAS / ENASEM 2024>
`

Descarga los archivos oficiales desde:

- SABE 2015: https://enlinea.minsalud.gov.co/Encuestas/Microdatos.aspx?E=SABE2015
- MHAS: https://www.mhasweb.org/DataProducts/CoreSurveyData.aspx

Solo se deben incluir los archivos necesarios para el análisis y las variables relevantes del catálogo. No se usan todos los archivos de la encuesta ni se redistribuyen.
